This Week 2 project implements and compares supervised machine learning models using Python and Scikit-learn. It covers all five algorithm families listed in the internship task: Linear Regression, Logistic Regression, Decision Trees, Random Forest, and K-Nearest Neighbors. The Diabetes dataset is used for regression, while the Breast Cancer Wisconsin Diagnostic dataset is used for binary classification. Four nonbaseline models are evaluated for each task, with dummy models included to establish meaningful reference performance.

The workflow uses a fixed 80/20 train-test split and five-fold cross-validation restricted to training data. Classification splits are stratified. Median imputation and appropriate standardization are included inside pipelines to prevent information leakage. Hyperparameters and the preferred algorithm are selected using cross-validation before the holdout set is evaluated. The classification target is explicitly remapped so that malignant cases are the positive class.

Regression performance is compared using MAE, RMSE, and R-squared. Classification performance is compared using accuracy, malignant-class precision, recall, F1, ROC-AUC, and confusion counts. Linear Regression is selected by cross-validation and achieves test RMSE of 53.85. Logistic Regression achieves test accuracy of 96.49%, malignant recall of 0.9286, and ROC-AUC of 0.9960.

The accompanying report goes beyond listing scores. It explains differences between cross-validation and test rankings, overfitting signals, large regression residuals, and why equal classifier accuracy can conceal different false-negative counts. Source code, dependency versions, data exports, model-search results, holdout predictions, and automated tests are included for reproducibility. Five tests passed, and a second complete run reproduced the recorded results exactly in the tested environment. These findings are educational benchmark results, not clinical validation or a guarantee of performance on new populations.
